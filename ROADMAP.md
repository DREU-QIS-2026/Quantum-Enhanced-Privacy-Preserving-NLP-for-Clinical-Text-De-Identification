# QuantumHPC Roadmap

This roadmap documents the development of the HPC and scalability work completed on the `kyle-hpc` branch of the DREU-QIS 2026 project.

The project evolved from an initial general-purpose quantum/HPC framework into a final experimental study of quantum-kernel simulation using real NinaPro biomedical EMG data, CPU and GPU simulation, MPI parallelization, multi-node execution, and Bridges-2 HPC resources.

### Final Kernel Definition

The final project uses

\[
K(x_i,x_j)
=
|\langle\psi(x_i)\mid\psi(x_j)\rangle|^2
\]

with quantum states generated by the manually implemented feature map.

### Parallelization Strategy

MPI is used for workload-level parallelism.

Independent quantum-state encoding and pairwise kernel evaluations are distributed among MPI ranks.

The implementation does **not** distribute one individual quantum statevector across multiple physical nodes.

### Observation

The original 102-window workload exposed measurable inter-node communication overhead.

The larger 714-window workload produced nearly identical single-node and multi-node runtimes at matched MPI process counts, indicating that the larger amount of pairwise computation substantially amortized the communication cost.

### Final MPI Outcome

The fastest measured full-capacity configuration used:

```text
1,404 distinct real EMG windows
986,310 quantum-kernel pairs
128 MPI ranks
16 physical Bridges-2 nodes
8 MPI ranks per node
0.365481 s mean runtime
11.486x speedup relative to one MPI process
```

Parallel efficiency declined substantially as MPI process count increased, demonstrating diminishing returns at high rank counts.

The fixed-128-rank topology experiment also showed that physical-node placement had a much smaller effect than total process-count scaling for the full-capacity workload.
