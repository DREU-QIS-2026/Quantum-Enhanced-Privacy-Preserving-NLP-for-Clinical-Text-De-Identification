# Goals

- Learn the fundamentals of quantum computing and Qiskit.
- Set up the project development environment.
- Build a manual implementation of the ZZFeatureMap without relying on built-in feature map classes.
- Develop the initial simulation framework.

---

# Approach & Implementation

Configured the Python development environment and installed Qiskit dependencies. Implemented a manual ZZFeatureMap using primitive quantum gates (Hadamard, Phase, and Controlled-X) to better understand circuit construction. Built an AerSimulator workflow capable of executing circuits, exporting circuit diagrams, generating measurement counts, logging runtime statistics, and recording experiment metadata. Organized the project into a modular directory structure to support future benchmarking and HPC development.

---

# Results

- Successfully implemented a manual ZZFeatureMap.
- Executed quantum circuits using Qiskit Aer.
- Generated circuit diagrams and simulation reports.
- Recorded statevectors, measurement counts, and runtime statistics.
- Established the initial project architecture for future benchmarking and MPI development.
