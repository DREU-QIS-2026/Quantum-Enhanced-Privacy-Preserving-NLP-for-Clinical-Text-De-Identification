## Purpose

Official specification defining MPI. Help understand distributed-memory parallel computing and determine how MPI can be incorporated into the QuantumHPC benchmarking framework.

---

## Summary

MPI defines a standardized communication interface allowing multiple independent processes to exchange data efficiently across CPUs and compute nodes. It is the dominant programming model for distributed-memory HPC systems.
